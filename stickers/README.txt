Folder stiker.

Stiker dari chat pribadi kamu otomatis masuk ke sini (yang kamu kirim
maupun yang kamu terima), lalu sesekali dipakai bot untuk membalas.

Kamu juga bisa menambah sendiri: taruh file .webp di folder ini.

Pengaturan di .env:
  STICKER_ENABLED=true/false   matikan total
  STICKER_CHANCE=0.15          peluang kirim stiker tiap balasan (15%)
  STICKER_COOLDOWN_MIN=30      jeda minimal per kontak (menit)
